Hospital Platform

医院平台统一后端服务 | Spring Boot 3.2.5 | Java 17 | QMG + Neuroimmune + OCR

统一后端平台整合两套核心业务：QMG 重症肌无力定量评分系统 与 Neuroimmune 神经免疫疾病随访系统，并提供 OCR、认证、审计、会话管理与 API 文档能力。

项目概述

QMG 模块

  • 基于 13 项临床指标进行量化评分，满分 39 分
  • 记录患者历史评分与病情变化趋势
  • 支持超级管理员、管理员、普通医生三级权限

Neuroimmune 模块

  • 覆盖 MS、NMOSD、MG、MOGAD、自身免疫性脑炎、GBS、CIDP 等疾病
  • 支持门诊 / 住院随访、用药方案、疾病发作记录
  • 提供医患绑定、扫码关联、角色化统计能力

认证机制

JWT Token 结构

{
  "userId": 1,
  "username": "doctor001",
  "role": "doctor",
  "module": "qmg",
  "exp": 1715000000
}

Token 存储（Redis）

Key:   hospital:token:{module}:{role}:{userId}
Value: Token 字符串
TTL:   24 小时（可配置）

认证流程

  1. 登录：验证用户名密码，生成 JWT，并写入 Redis
  2. 请求：通过 Authorization: Bearer {token} 携带凭证，由过滤器校验并解析用户信息
  3. 踢下线：删除 Redis 中 Token，用户后续请求被拒绝

常见问题

Token 验证失败怎么办？

  1. 检查 Token 是否过期，默认有效期为 24 小时
  2. 确认 Redis 中仍存在对应 Token
  3. 确认请求头格式为 Bearer {token}

如何踢用户下线？

调用 /api/v1/admin/session/kick：

{
  "userId": 1,
  "role": "doctor",
  "module": "qmg"
}

数据库连接失败？

  1. 确认 MySQL 已启动
  2. 确认数据库 QMG 与 neuroimmune 已创建
  3. 确认用户名密码正确
  4. 确认连接 URL 配置正确
